# Player Create Helper Quick Start

1. Download `Player Create Helper.zip` from GitHub
2. Unzip it
3. In Figma, go to `Plugins > Development > Import plugin from manifest...`
4. Select `manifest.json` inside the unzipped folder
5. Select one template pair: `cf-img` and `cf-bg`
6. Run `Player Create Helper`
7. Upload album covers and generate assets
